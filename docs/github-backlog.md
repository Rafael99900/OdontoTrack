## Regra de movimentação

`Backlog` → `Pronto para desenvolvimento` somente com critério de aceite definido.

`Em desenvolvimento` quando houver implementação iniciada em branch associada.

`Em revisão` quando houver demonstração funcional, testes e evidência de aceite.

`Concluído` somente após aceite funcional, documentação atualizada e sem bloqueio crítico.
